# 工作区与 Codex 选择器界面调整

后续界面以 [2026-10-23 大纲页内引用与助手输入框](2026-10-23-outline-references.md) 为准：模型选择移入输入框，主题设置移入设置页，大纲关联栏改为页内引用。

本票修复顶部页签随中间区域宽度漂移、大纲滚动条没有获得阅读区高度的问题，并调整 Paper 配色和助手模型选择界面。

- 正文 / 大纲 / 笔记放到独立的窗口顶部工具栏，三个按钮等宽。大纲关联栏、项目侧栏和助手的宽度变化不再移动页签。
- 大纲阅读与源码共用 `DocumentScrollBar.qml`，显式连接阅读区高度，保留固定留白，增大长文档滚动滑块的最小尺寸。
- Paper 使用暖白、石墨文字和低饱和绿灰强调色，保留原有主题切换方式。
- `CodexChoiceBox.qml` 提供向上弹出的模型 / 思考强度菜单及当前选项勾号，支持方向键、回车和 Escape。模型名称按纯文本显示。
- 助手输入框下方显示紧凑选择器；`/model` 打开同一菜单。顶部“会话与用量”保留联网、账号、用量和会话控件，可再次点击收起。

修改文件：`App.qml`、`WorkspaceTabs.qml`、`OutlinePage.qml`、`DocumentScrollBar.qml`、`theme_provider.py`、`CodexChoiceBox.qml`、`CodexControls.qml`、`AgentComposer.qml`、`CreativeAgentPanel.qml`，以及对应工作区、主题和选择器测试。

验证：51 项相关 UI / Markdown / 主题 / Codex 控件测试通过；Ruff 与差异检查通过。Windows 实际窗口验证涵盖三页切换、滚动条拖动、模型与强度选择、会话控件收起、三种主题及 1100 像素窄窗口。实际窗口中的页签中心坐标在同尺寸切换时保持一致；QML 警告为零；临时大纲和正式正文内容保持不变。

模型列表继续来自既有 Codex 连接，没有在产品中写死截图中的模型。测试与截图只使用临时项目、模拟目录和独立的临时设置文件，不访问作者小说或调用写作模型。

本票不修改数据库结构、正文输入流程、密钥或全局 Codex 配置。改动保留在当前功能工作树，尚未提交或替换桌面旧入口；使用本工作树的 `启动程序.bat` 重启后生效。
