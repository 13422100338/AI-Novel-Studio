# 小说工作台 UI 优化

分支：`codex/frontend-novel-ui-polish`，基线：`9ea3ec0`。本票只修改前端控件、排版与显示，不修改后端接口、存储、模型调用或作者小说。

## 本轮变化

| Before | After | Why |
| --- | --- | --- |
| 按钮与系统下拉框、输入框样式混杂 | 统一暖纸色控件、36px高度、13px字体与焦点边框 | 提升辨识度，支持键盘操作 |
| 章节标题只显示一行，4个操作按钮横向拥挤 | 标题可显示两行，操作按钮改为两列 | 避免截断与侧栏溢出 |
| 模型、强度、会话和按钮挤在一行 | 模型及强度按字段分组，会话使用独立行 | 减少拥挤并保留完整名称 |
| 输入区较矮，长提示占据编辑区域 | 提高输入区、单独显示发送快捷键，常用动作使用轻按钮 | 改善输入与操作层级 |
| 写作 API 表单缺少主次层级 | 区分 Codex 助手与独立写作连接，突出保存按钮，窄窗口自动上下排布 | 更容易找到要修改的配置 |
| 正文长行与段落间距偏紧 | 17px正文、1.85行高、840px最大阅读宽度与自适应内边距 | 适合持续阅读与写作 |
| WebEngine容器右侧、底部存在黑边 | 去除宿主与WebEngine之间的偏移边距，补充高度变化后的重绘 | 原生预览确认黑边消失 |

主要文件位于 `ui_qml/qml/components`、`qml/pages`、`App.qml` 和 `editor_web/src/style.css`。新增 `AppComboBox.qml`、`AppTextField.qml`，`AppButton.qml` 改用 Qt 标准 Button 的交互与可访问性能力，保持原有点击回调。

## 验证

- 71项相关前端测试分组通过：外壳/消息布局45项、表单/模型/响应式布局/编辑器接线26项。
- 新增 `test_ui_polish_layout.py`，验证1100/1440宽度下章节操作不溢出，并验证按钮键盘激活。
- 编辑器使用锁定依赖从缓存安装，`npm run build` 成功；新增测试的 Ruff 检查通过，Git 差异检查通过。
- 原生窗口使用新建测试小说检查设置、侧栏、正文和模型目录。未打开或修改作者小说，未修改全局模型设置、API密钥或后端工作树。

## 启动与范围

此版本入口为本前端工作树的 `启动程序.bat` / `launch.bat`；现有窗口不会自动更新。前端工作树已构建编辑器资源，可直接运行。若另行创建干净检出，需按现有流程构建 `ui_qml/editor_web`。

本票未合并到后端工作树或主分支。保留现有暖纸色、导航结构和功能；其他主题、更多页面细节可在后续票继续优化。
